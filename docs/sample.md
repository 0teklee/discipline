# 네트워크 기초 개념 정리

## Q: OSI 7계층 모델에서 3계층(네트워크 계층)의 주요 역할은?
A: 라우팅(경로 결정)과 논리적 주소 지정(IP 주소)
> 네트워크 계층은 패킷을 목적지까지 전달하는 경로를 결정하며 IP 프로토콜이 대표적입니다.
Tags: 네트워크, OSI

## Q: TCP와 UDP의 차이 중 올바른 것은?
- TCP는 비연결형이고 UDP는 연결형이다
- TCP는 신뢰성 있는 데이터 전송을 보장하고 UDP는 보장하지 않는다
- UDP는 흐름 제어를 제공하고 TCP는 제공하지 않는다
- TCP와 UDP 모두 순서 보장을 제공한다
A: TCP는 신뢰성 있는 데이터 전송을 보장하고 UDP는 보장하지 않는다
> TCP는 3-way handshake, 흐름 제어, 오류 재전송을 통해 신뢰성을 보장합니다.
Tags: 네트워크, TCP, UDP

## Q: HTTP 상태 코드 404의 의미는?
A: 요청한 리소스를 서버에서 찾을 수 없음 (Not Found)
> 클라이언트가 요청한 URL에 해당하는 리소스가 서버에 존재하지 않을 때 반환됩니다.
Tags: HTTP, 상태코드

## Q: 서브넷 마스크 255.255.255.0을 CIDR 표기법으로 나타내면?
A: /24
> 255.255.255.0은 이진수로 앞에서 24개의 비트가 1이므로 /24입니다.
Tags: 네트워크, IP, CIDR

## Q: DNS의 주요 기능은?
- IP 주소를 MAC 주소로 변환한다
- 도메인 이름을 IP 주소로 변환한다
- 패킷의 라우팅 경로를 결정한다
- 데이터를 암호화하여 전송한다
A: 도메인 이름을 IP 주소로 변환한다
> DNS(Domain Name System)는 사람이 읽기 쉬운 도메인 이름을 컴퓨터가 처리할 수 있는 IP 주소로 변환합니다.
Tags: 네트워크, DNS

## Q: HTTPS가 HTTP와 다른 핵심 특징은?
A: TLS/SSL을 통한 암호화 통신으로 데이터 기밀성과 무결성을 보장
Tags: HTTP, 보안, TLS

## Q: ARP 프로토콜의 역할은?
- 도메인 이름을 IP로 변환
- IP 주소를 MAC 주소로 변환
- MAC 주소를 IP 주소로 변환
- 포트 번호를 서비스명으로 변환
A: IP 주소를 MAC 주소로 변환
> ARP(Address Resolution Protocol)는 IP 주소를 기반으로 해당 호스트의 MAC 주소를 알아내는 프로토콜입니다.
Tags: 네트워크, ARP

## Q: 3-way handshake 과정을 순서대로 나열하면?
A: SYN → SYN-ACK → ACK
> TCP 연결 수립 시 클라이언트가 SYN을 보내고, 서버가 SYN-ACK로 응답하며, 클라이언트가 ACK를 보내 연결을 완성합니다.
Tags: TCP, 3-way handshake

## Q: 로드 밸런서의 주요 역할은?
- 데이터를 압축하여 전송 속도를 높인다
- 여러 서버에 트래픽을 분산하여 가용성과 성능을 향상시킨다
- 악성 트래픽을 차단하는 방화벽 역할을 한다
- DNS 캐싱을 통해 응답 속도를 높인다
A: 여러 서버에 트래픽을 분산하여 가용성과 성능을 향상시킨다
Tags: 인프라, 로드밸런서

## Q: IPv6 주소의 길이는?
A: 128비트
> IPv4는 32비트(4바이트)이지만, IPv6는 주소 고갈 문제를 해결하기 위해 128비트(16바이트)를 사용합니다.
Tags: 네트워크, IPv6
