# Discipline

## 학습 웹 어플리케이션

- Context Agnostic : 모든 종류의 자격증 시험, 지식, 기타 등등을 문제-정답, 객관식/주관식 형식으로 문제푸는 사이트
- 문제 base knowledge:
  1. markdown, pdf, html 등등 문제-답안 형태 혹은 이론 정리한 형태를 로컬에서 업로드함
  2. 전처리 후 데이터 : 일정한 포맷을 따르는 단일한 형태로 문제 가공
  3. 이 데이터를 기반으로 문제-정답 기준을 생성하여 저장
  4. 이 데이터 기반으로 해당 시험 페이지에 문제 생성

## 스펙 및 동작 사항

- 로컬 호스트에서만 동작
- 브라우저 로컬 히스토리에 사용자 점수와 날짜/월별 점수 등등 저장
- 특정한 포맷으로 학습 자료 저장 시 스크립트로 전처리하여 문제 생성
- 메인 페이지 : 현재 점수, 저장된 문제 / 이론 / 지식
- 시험 페이지 : 인풋에서 생성된 문항 기반으로 랜덤 순서로
- 시험 결과 페이지: 틀린 문항, 맞춘 문항 개수, 틀린 문제 / 맞춘 문제 목록
- 가장 효율적인 포맷으로
- vite + tailwindCSS + shadcn으로 프론트엔드만 빌드
- 기타 점수 등등은 로컬 스토리지 혹은 프로젝트 레포에 파일로 저장
- 로컬 LLM 혹은 Claude/OpenAI api 연동하여 문제 생성 기능 구현
